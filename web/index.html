TRANSPARENCY BY DESIGN

How the smaller portfolio is built.

We search for a small basket whose daily returns approximate the benchmark, with no short selling and a maximum starting weight of 25% per stock.

  1. Train (60%). Greedily add stocks that explain the remaining return difference. Fit fully invested, capped weights using constrained ridge least squares.
  2. Validate (20%). Normalize holding budget and tracking RMSE to the same scale. Select the point closest to the ideal of fewest holdings and lowest error, giving both equal importance. This grid-dependent balance is a transparent preference, not a global optimum.
  3. Test (20%). Freeze the support, refit weights on train + validation, and evaluate the subsequent untouched period. Test results never drive the automatic choice.

What the numbers mean

Tracking error: standard deviation of daily portfolio-minus-benchmark returns, annualized with √252. Tracking RMSE: root mean squared active returns, annualized with √252; also penalizes persistent daily return bias. Return difference: cumulative portfolio return minus cumulative benchmark return, in percentage points.
